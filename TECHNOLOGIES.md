# Technologies

This document describes the technologies used in the project at a high level.

## Flutter

Flutter was used to build the mobile application interface and organize the app experience across supported platforms.

## Dart

Dart is the programming language used to develop the Flutter application.

## Firebase Authentication

Firebase Authentication supported user sign-in and registration, including:

- Email and password
- Google sign-in

The exact authentication configuration and provider settings are intentionally not included in this public documentation repository.

## Cloud Firestore

Cloud Firestore was used as the application's database service for application data.

This document does not prescribe or claim the exact production collection names or field schema.

## Firebase Storage

Firebase Storage was used for storing images/files associated with the application.

Do not upload real user images or private project data to this repository.

## MapTiler

MapTiler was used for the map integration and map visualization experience.

No API key or private access token should be committed to this repository. Follow MapTiler's current guidance for restricting and configuring public client-side keys.
