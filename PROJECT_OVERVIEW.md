# Project Overview

## The idea

Engelsiz Rota is an accessibility-focused mobile application project. Its purpose is to make accessibility barriers easier to report, locate, and review.

## The problem space

People navigating public spaces may encounter barriers that are not clearly documented. Sharing structured information about these barriers can help raise awareness and support better-informed mobility decisions.

## Project objectives

- Provide a mobile interface for user registration and sign-in.
- Allow users to submit accessibility-related reports.
- Associate reports with location information and photographs.
- Present map information through MapTiler.
- Provide an administrative area for reviewing and managing submitted content.

## High-level user journey

1. Register or sign in.
2. Open the map or reporting area.
3. Submit a report with relevant details.
4. Attach a photograph when appropriate.
5. Allow authorized administrators to review and manage reports.
